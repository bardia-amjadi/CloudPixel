Local Version Manager

VerHub

VerHub یک Local Version Manager است که روی پورت 5055 اجرا می‌شود و امکان مدیریت نسخه‌های مختلف پروژه‌ها و ابزارها را در محیط لوکال فراهم می‌کند. هدف آن ساده‌سازی مدیریت نسخه‌ها و ایجاد تجربه‌ای سریع برای توسعه‌دهندگان است.

Download Release GitHub
معرفی

VerHub چیست؟

در پروژه‌های واقعی، مدیریت نسخه‌های مختلف ابزارها و کتابخانه‌ها در محیط لوکال یکی از چالش‌های مکرر توسعه‌دهندگان است. VerHub با اجرا‌شدن به‌صورت یک سرویس سبک روی پورت 5055، این فرآیند را متمرکز و ساده می‌کند.

به‌جای جابه‌جایی دستی بین نسخه‌ها یا نگهداری اسکریپت‌های پراکنده، VerHub یک نقطه واحد برای مشاهده، سوییچ و مدیریت نسخه‌ها در اختیار توسعه‌دهنده قرار می‌دهد.

verhub.sh 
# اجرای سرویس VerHub
$ verhub start

# خروجی
VerHub is running on http://localhost:5055
Watching local project versions...
Status: ready
